# 🌱 Plant Disease Detector

An AI-powered web application that detects plant leaf diseases from uploaded images using a deep learning image classification model.

## 📌 Project Overview

Plant diseases can affect plant growth and crop production. Identifying diseases from leaf symptoms can be difficult, especially when done manually.

This project uses **Deep Learning** and **Computer Vision** to analyze a plant leaf image and predict the corresponding disease class.

The application provides:

- 🌿 Plant leaf image upload
- 🤖 AI-based disease prediction
- 📊 Prediction confidence percentage
- 🖼️ Uploaded image preview
- ⚠️ Low-confidence prediction handling
- 🌐 User-friendly web interface

## 🧠 Machine Learning Model

The project uses a **Convolutional Neural Network (CNN)** for image classification.

The model performs the following operations:

1. Image resizing
2. Image normalization
3. Convolution
4. Max pooling
5. Feature extraction
6. Fully connected classification
7. Disease prediction
